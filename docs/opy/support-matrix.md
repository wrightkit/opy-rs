# Support query projection

The canonical public OverPy compatibility contract is
[`../language-support.md`](../language-support.md). Its linked inventories are
the complete audited support documentation for pinned OverPy `9.7.10`.

The CLI support query reads the embedded
[`crates/opy-rs/support-matrix.json`](../../crates/opy-rs/support-matrix.json)
projection. The exhaustive public contract is
[`../language-support.md`](../language-support.md) and its linked inventories;
the projection must not introduce another public status vocabulary.
